This program is a file encryptor, as the name suggests.
The purpose of the program is for users to input files of varying types and safely encrypt them with a user-inputted password.
The program will also decrypt and retrieve these files given you have the corresponding password.
Both encrypted files and decrypted files will be uploaded to your local drive.

Note: This program runs independently. Files that are encrypted using this program can only be decrypted using this program.
Conversely, this program can only decrypt files encrypted by this program.

You can download the the file by clicking on the <code> button and downloading the zip file.

Parts of these codes were derived (but not one-for-one) from some tutorials on encryption.
